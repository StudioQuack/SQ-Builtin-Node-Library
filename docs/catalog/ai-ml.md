# AI & Machine Learning

StudioQuack models this category as **one node per API provider**. Chat, embeddings, images, audio, files, and moderation are `operation` values on that node — never a cluster of per-capability sibling nodes. Ports are **one INPUT + one OUTPUT** except the **AI Agent**, which uses FUNCTION ports to call an LLM and tools N times at runtime. LLM provider nodes speak the v2 `llm_input` → `llm_output` contract so they can sit on the Agent `model` FUNCTION port. Secrets are StudioQuack secret bindings; never literals in graph JSON.

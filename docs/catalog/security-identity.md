# Security & Identity

Provider nodes for IdP/IAM, directory, secrets vaults, token/2FA utilities, and threat-intel lookups. One node per API provider (or one utility node when there is no vendor). Token/2FA utilities (JWT, LDAP, TOTP) sit next to the IdP and vault providers (Okta, Bitwarden, Entra, Cognito, IAM, TheHive, MISP, Cortex, Elastic Security); secrets-manager and bot-score APIs follow the same one-node rule. Ports are one INPUT and one OUTPUT. Secret values must be resolved just-in-time from the OS secret manager, never written to engine variables or logs.

HTTP providers are `OfficialApiNode` packages under `nodes/<slug>/` (`node_definition.json`, `api_spec.json`, `README.md`). `listen` / `trigger` is `kind:ingress` (BPMN message event — no socket). JWT and TOTP are local protocol utilities OfficialApiNode cannot execute; LDAP is an in-process JNDI handler (`LdapNode`).

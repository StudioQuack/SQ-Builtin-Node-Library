# Utilities & Core

Data-shape and generic connectivity nodes (no third-party SaaS brand except protocol servers). Flow control is NOT a node: branching, merging, waiting, scheduling, error handling, and sub-process invocation are BPMN constructs of the engine (exclusive / inclusive / parallel / complex / event-based gateways, timer / error / message events, call activity) and never appear in this catalog. Inbound StudioQuack webhooks are also NOT a node: external senders hit the StudioQuack engine's message-event ingress, which correlates onto message start / intermediate catch / boundary message events. File payloads use the `file` type on ports and configuration parameters (a ref-id, never inline bytes). One node per capability; pick work with `operation`. Default ports are one INPUT + one OUTPUT. FUNCTION ports exist only when the node must invoke another node or sub-process N times at runtime. HTTP Request already ships as a custom handler (`nodes/http-request`). The other rows are packaged under `nodes/<slug>/` (`node_definition.json`, `api_spec.json`, `README.md`) and register through `OfficialApiNode`.

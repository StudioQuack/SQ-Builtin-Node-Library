# News & Reference

StudioQuack models news wires, scholarly indexes, encyclopedias, stock media, and lexical APIs as **one node per API provider**. Search vs headlines vs lookup are `operation` values. Ports are **one INPUT + one OUTPUT**. Feed reading and feed listening collapse into one RSS node: `read` is HTTP GET; `listen` is `kind:ingress` (BPMN message event — the node does not poll or open a socket). Attribution and redistribution limits are part of the vendor ToS — NewsAPI in particular forbids filling a news product from the free tier. Google Trends in this library already uses an unofficial widget path and is flagged. Secrets are StudioQuack bindings. Rows marked `done` have `nodes/<slug>/{node_definition.json,api_spec.json,README.md}` (`OfficialApiNode`).

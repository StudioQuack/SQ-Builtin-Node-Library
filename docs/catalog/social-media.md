# Social Media

StudioQuack models each network as **one node per API provider**. Publish, search, insights, and webhook listen are `operation` (today some shipped nodes use `action`) values — never a YouTube-Upload node beside a YouTube-Search node. Ports are **one INPUT + one OUTPUT**. Discord, Telegram, and WhatsApp are listed here for discovery; the **canonical node is communication-messaging.md** (do not fork). Platform ToS apply: official APIs only, no session-cookie scrapers, branded-content / AI-disclosure flags where the network requires them. Secrets are StudioQuack bindings.

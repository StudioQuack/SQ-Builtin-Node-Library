# Files & Documents

Cloud file/object stores, S3-compatible endpoints, FTP, e-sign, PDF services, OCR/IDP, and local office conversion as **one node per provider**. Choose the API call with `operation`. Google Drive, OneDrive, and SharePoint are the same nodes as in Productivity & Collaboration (`nodes/google-drive`, `nodes/microsoft-onedrive`, `nodes/microsoft-sharepoint`). File payloads use the `file` type on ports and configuration parameters (a ref-id, never inline bytes).

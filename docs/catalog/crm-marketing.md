# CRM & Marketing

CRM, email/lifecycle marketing, forms, product analytics, paid ads, landing/CRO, conversational marketing, and SEO tools. **One node per API provider**; the designer picks an `operation` (never a separate node per verb). Almost every node is **one INPUT + one OUTPUT**. Trigger/webhook providers expose a `trigger.listen` operation on the same node (event type is a config param), not a second node. HubSpot Marketing Hub is **not** a separate node — it shares HubSpot’s CRM API. Tokens live in the daemon secret store (never logs). Callers own GDPR/CCPA consent, CAN-SPAM/CASL, and each vendor’s API ToS.

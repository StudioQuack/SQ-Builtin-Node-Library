# Developer Tools

Source control, CI/CD, incident/observability, package registries, and cloud deploy APIs. One node per provider; resources and verbs are `operation` values (never a node per verb). Default ports are one INPUT + one OUTPUT. Provider webhooks are a `listen` operation on the same node. GitHub already ships in this library (`nodes/github`) as a read-only search subset — catalog ops below are the full REST surface to grow into. AWS / GCP / Azure are each one node with a `service` selector plus `operation`.

# Data & Analytics

Web search, scholarly catalogs, news, weather, geocoding, IP/phone intel, markets, and public statistics. **One node per API provider**; the designer picks an `operation` (never a separate node per verb). Feed read vs listen and LLM “tool” usage fold into the same node as `feed.read` / `trigger.listen` / `search`. Almost every node is **one INPUT + one OUTPUT**. 57 rows ship as library nodes (`done`): eight custom handlers plus 49 OfficialApiNode packages. Bing Web Search and Yahoo Finance stay `planned` / **DO NOT BUILD**. RSS `read` GETs the feed; `trigger.listen` is BPMN ingress. Tokens live in the daemon secret store (never logs). Callers own each vendor’s ToS, rate limits, and redistribution rules — **do not scrape HTML when an official API exists**, and do not scrape when none exists.
